Rajarata Banking App

📌 Project Overview

The Rajarata Banking App is a mini project developed as part of the ICT 2304 – Object Oriented Programming course at Rajarata University of Sri Lanka. The application simulates a digital banking system that allows users to manage accounts and perform essential banking operations in a secure and user-friendly manner.This project focuses on applying Object-Oriented Programming (OOP) concepts to design a scalable and maintainable banking application using Java.

🎯 Objectives

Simulate real-world digital banking operations
Apply core OOP principles in a practical scenario
Develop a secure and structured Java-based application
Improve teamwork, coding standards, and problem-solving skills

🛠️ Features

Secure user registration and login
View account details and balances
Deposit and withdraw funds
Fund transfers between accounts
Transaction history tracking
Basic input validation and error handling

🧩 OOP Concepts Used

Encapsulation – Protecting account and user data
Inheritance – Reusing common account properties
Polymorphism – Handling different account behaviors
Abstraction – Defining common banking operations
Composition – Relationship between users, accounts, and transactions
Exception Handling – Managing invalid inputs and errors
File Handling / Collections – Storing user and transaction data

💻 Technologies Used

Programming Language: Java
Development Environment: IntelliJ IDEA / Eclipse / NetBeans
Platform: Desktop Application

▶️ How to Run the Project

Clone or download the project repository
Open the project in your preferred Java IDE
Compile and run the main class

Follow on-screen instructions to use the banking features
